## 中文

- 中文实体键盘模式支持 `Shift+C` 复制和 `Shift+V` 粘贴。配置 SyncClipboard 后，粘贴前会检查远端。有新内容时先下载，否则使用本地剪贴板。
- 连按两次 `v` 打开居中的半透明表情选择器。用 `-` / `_` 和 `=` / `+` 切换分类，方向键选择表情，Enter 或空格确认，Esc 关闭。当前分类和选中的表情都有独立描边。
- 中文实体键盘模式下，`{` 与 `}` 分别输入 `「` 与 `」`。
- 切换输入框时，实体键盘模式按需显示候选栏。手动下载后若写入系统剪贴板失败，剪贴板面板会显示提示。

日常使用请选择 `ukb-chinese-input-2.4.0-release.apk`。同签名旧版支持直接覆盖安装。调试版使用独立包名，可以并装。

## English

- Use `Shift+C` to copy and `Shift+V` to paste in Chinese physical keyboard mode. If SyncClipboard is configured, paste checks for new remote content first and falls back to the local clipboard.
- Press `v` twice to open a centered, translucent emoji picker. Use `-` / `_` and `=` / `+` to change category, arrow keys to select, Enter or Space to insert, and Esc to dismiss. The active category and emoji have separate outlines.
- In Chinese physical keyboard mode, `{` and `}` type `「` and `」`, respectively.
- Physical keyboard candidates appear as needed when switching text fields. Manual downloads report any failure to write to the system clipboard.

Use `ukb-chinese-input-2.4.0-release.apk` for daily typing and in-place upgrades from builds with the same signature. The debug APK can be installed alongside it.
